# Parts Inventory

Mobile-first Next.js app for looking up appliance parts, bin locations, and stock levels against open service jobs.

## What’s included

- Parts list with search (part number, description, or bin) and stock filters
- Part detail pages with quantity on hand and related jobs
- Jobs view showing the parts each call needs and whether they are short
- Mock catalog of 5 common appliance parts

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://localhost:43127](http://localhost:43127).

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Lucide React
